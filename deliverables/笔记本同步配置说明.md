# 笔记本（E盘）一次性配置说明

> 目的：让笔记本能拉取/推送金水谣代码，和台式机共用 GitHub 同步。
> 坚果云流量恢复后，Obsidian 笔记会自动同步（vault 在坚果云里，无需配置）。
> 这套配置只做一次，以后不用管。

## 一、安装 Git（5分钟）

1. 打开浏览器访问：https://git-scm.com/download/win
2. 下载 64-bit 版，双击安装
3. 一路"Next"，**到"Adjusting your PATH"那一步，选第2项**（Git from the command line），继续装完
4. 装完后按 `Win+R` 输入 `cmd` 回车，输入下面命令验证：
   ```
   git --version
   ```
   显示 `git version 2.x.x` 就成功了

## 二、生成并绑定 SSH 密钥（一次性）

在 cmd 里执行（**邮箱换成你自己的 GitHub 邮箱**）：

```
ssh-keygen -t ed25519 -C "你的GitHub邮箱" 
```

一路回车（密码留空）即可。

然后显示密钥内容并复制：

```
type %USERPROFILE%\.ssh\id_ed25519.pub
```

登录 GitHub → 右上角头像 → Settings → 左侧 SSH and GPG keys → New SSH key →
标题随便填（如"笔记本"），把复制的内容粘贴进去 → Add SSH key。

## 三、拉取代码（每台笔记本只做一次）

在 cmd 里执行（先建好目录，比如 `E:\金水谣`）：

```
cd /d E:\
git clone git@github.com:y168521/Jinshuiyao_Fixed.git 金水谣
```

首次会问 `Are you sure you want to continue connecting?` 输入 `yes` 回车。

完成后你的代码在 `E:\金水谣\`。

## 四、以后怎么同步（记住两个动作）

**开工前**（拿到台式机最新代码）：
```
cd /d E:\金水谣
git pull
```

**收工后**（把笔记本改的推回 GitHub）：
```
cd /d E:\金水谣
git add -A
git commit -m "笔记本更新"
git push
```

> 台式机那边每 30 分钟会自动同步一次，你笔记本 push 后台式机会自动合并。
> 两台机器**不要同时改同一个文件**，否则 pull 会冲突，报错时把错误发 AI 处理。

### 中文文件名乱码修复（clone 后做一次）

如果 `git status` 里中文文件名显示成 `\350\207\252...` 这样的数字乱码，执行：

```
cd /d E:\金水谣
git config core.quotepath false
```

执行后中文文件名就会正常显示了。笔记本 clone 后建议马上执行一次。

## 五、（可选）全自动同步（和台式机一样省心）

克隆完成 + 上面的乱码修复做过后，可以设置**每 30 分钟自动同步**（检测到笔记本的改动会自动提交推送，台式机的改动会自动拉下来），不用手动敲命令。

把下面内容存成 `E:\金水谣\自动同步.ps1`（用记事本保存时编码选 **UTF-8**）：

```powershell
# 金水谣笔记本自动同步：每30分钟 pull 台式机改动 + 提交推送笔记本改动
$ErrorActionPreference = "SilentlyContinue"
$Repo = "E:\金水谣"
$env:GIT_SSH_COMMAND = "ssh -o StrictHostKeyChecking=accept-new -o BatchMode=yes -o ConnectTimeout=15"
Set-Location -LiteralPath $Repo
git -c core.quotepath=false pull --rebase origin master 2>&1 | Out-Null
$pullOk = $LASTEXITCODE -eq 0
if (-not $pullOk) { exit 1 }
$rows = git -c core.quotepath=false status --porcelain 2>$null | Where-Object { $_ -and $_.Length -gt 3 }
$noise = @("correlation_matrix.json","predictions.json","auto_audit_report.json","brain_state.json","auto_sync.log","token_usage.json","server\config.py","__pycache__",".ruff_cache",".pytest_cache")
$candidates = @()
foreach ($r in $rows) {
    $p = $r.Substring(3).Trim('"').Replace("/","\")
    $skip = $false
    foreach ($n in $noise) { if ($p -like "*$n*") { $skip = $true; break } }
    if (-not $skip) {
        $ext = [IO.Path]::GetExtension($p).ToLower()
        if ($ext -in @(".py",".md",".bat",".html",".css",".js",".json",".sh")) { $candidates += $p }
    }
}
if ($candidates.Count -gt 0) {
    foreach ($c in $candidates) { git add -- "$c" 2>&1 | Out-Null }
    $staged = git diff --cached --name-only 2>$null | Where-Object { $_ }
    if ($staged.Count -gt 0) {
        git commit --no-verify -m "laptop-sync: $(Get-Date -Format 'yyyy-MM-dd HH:mm')" 2>&1 | Out-Null
        git push origin master 2>&1 | Out-Null
    }
}
exit 0
```

然后以**管理员身份**打开「命令提示符」，粘这段回车（30 分钟自动跑一次）：

```
schtasks /create /sc minute /mo 30 /tn "Jinshuiyao笔记本同步" /tr "powershell -NoProfile -ExecutionPolicy Bypass -File E:\金水谣\自动同步.ps1" /f
```

验证：`schtasks /query /tn "Jinshuiyao笔记本同步"` 能显示任务就成功了。

> 注意：这台笔记本的脚本独立于台式机（路径是 E:\金水谣），两台机器各管各的，共用一个 GitHub。
> 以后不想自动了：`schtasks /delete /tn "Jinshuiyao笔记本同步" /f`

## 六、（可选）开机自动启动金水谣

和台式机一样，把 `E:\金水谣\launch.bat` 建个快捷方式放进启动文件夹：
1. 右键 `E:\金水谣\launch.bat` → 创建快捷方式
2. 按 `Win+R` 输入 `shell:startup` 回车，把快捷方式拖进去
3. 以后开机自动启动服务器（端口 18888），网页看板 http://localhost:18888 直接点开
