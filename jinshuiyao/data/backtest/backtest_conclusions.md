# 金水谣 P1 真实赛果回测结论清单（data-scientist / 赛奇）

> 输入（只读）：`matches_real.csv`（143 场 · 2025-26 五大联赛真实完赛结果，采集日 2026-07-28）
> 分析对象：验证"真实赔率隐含概率"是否校准到"真实赛果频率"，并评估简单预测策略命中率
> 环境：venv（pandas 3.0.3 / numpy 2.5.1 / scipy 1.18.0），种子 seed=42
> 输出文件：`backtest_metrics.json`（结构化指标，供 dashboard / report 下游消费）

---

## 一、数据概要

- **规模**：143 场 = 英超 30 + 西甲 40 + 德甲 25 + 意甲 30 + 法甲 18
- **字段**：`result` 为中文 `主胜/平/客胜`，已映射为 `H/D/A`
- **性质**：真实赛果，非演示数据；**无逐场赔率**（仅 `result/score`）
- **方法可追溯**：
  - 实际频率 = `matches_real.csv` 逐场计数 ÷ 联赛场次
  - 隐含概率（英超/西甲）= 诺亚 WebSearch 真实赔率 `1/odds`（含庄家 margin）：英超 2.2/3.98/3.4，西甲 1.9/3.5/4.0
  - 隐含近似（德甲/意甲/法甲）= 诺亚外部赛季基准实际频率（无逐场赔率）
  - Brier = 常数隐含向量预测本样本 one-hot，`Brier = mean((p − y)²)`
  - margin（overround）= Σ `1/odds`
  - 代表性 = 本样本实际 vs 外部基准 + 卡方拟合优度（df=2）

## 六、核心发现

**① 庄家 margin 系统性高估：部分成立。**
西甲 overround=1.062（+6.2% margin）→ 隐含概率系统性高估真实概率约 6%，符合诺亚"5~10%"假设。但英超这组赔率（2.2/3.98/3.4）overround≈1.000（−0.01%）→ 几乎零 margin，不构成系统性高估（接近无套利定价）。**结论：margin 高估只在存在 overround 时成立；英超该组赔率恰好近似公平盘，需用多组赔率交叉验证。**

**② 英超 draw 市场存在 mispricing：成立（样本+外部双重印证）。**
隐含 draw 25.1% < 实际 draw 30.0%（本样本，+4.9pp）且 < 外部赛季 27.4%（+2.3pp）→ 平局被市场低估，"backing draw" 具正期望，与 dedicatedbetting "backing draw +6.5% ROI" 一致。同时英超 home 隐含 45.5% 略高于实际 43.3%（−2.1pp）。

**③ 主场优势：外部基准法甲最强(50%)、意甲最弱(37%)；本样本因抽样出现点估计倒置，需谨慎。**
外部赛季基准：法甲 home 50% 最高、意甲 home 37% 最低，与诺亚陈述一致。但本样本意甲 home 43.3% > 法甲 home 38.9%（倒置）。卡方检验显示两样本与各自基准均无显著差异（p=0.77/0.64），属抽样噪声。**主场优势结论应采信外部大样本基准，本样本仅作一致性佐证。**

**④ 简单"选最高隐含/最低赔"策略未创造超额收益，命中率=该方实际频率。**
各联赛 argmax(隐含) 均为主胜，命中率=该联赛主胜实际频率。总体 +8.6pp 实为"主胜在多数联赛是众数"的分布红利，非策略战胜市场。**反例：德甲本样本主胜仅 32.0% < 随机 33.3%（−1.3pp）——"无脑选主胜"在平局偏多的联赛（德甲样本 D=36%）会失效。** Brier 0.21~0.23 远胜随机 0.667，但这是边际信息红利，非逐场信号。

**⑤ 西甲出现 draw 高估 / away 低估的试探性 mispricing 信号（待验证）。**
本样本西甲 draw 实际 20.0% ≪ 隐含 28.6%（−8.6pp），away 实际 32.5% ≫ 隐含 25.0%（+7.5pp）。提示西甲平局被高估、客胜被低估。但 n=40、西甲无外部基准对照，且西甲历史 draw 率通常 ~22-25%（20% 偏低），可能为后期轮次（R26/32/34/38）抽样效应。**标注为试探性信号，需逐场赔率 + 更大样本确认。**

**⑥（补充）样本代表性统计可信。**
4 个有外部基准的联赛卡方 p 均 > 0.26，无法拒绝"本样本=赛季基准"。matches_real.csv 可支撑下游建模，但单联赛结论置信区间宽。

## 七、数据缺口声明（务必随报告披露）

1. **无逐场赔率**：matches_real.csv 仅含 `result/score`，无赛前 odds。本回测为**联赛聚合级**，非 143 场逐场回测。完整"赔率→赛果"逐场回测须接入历史赔率 API（如 OddsPortal 归档 / 足球数据 API），按 `match_id` 或 球队+日期 对齐。
2. **德甲/意甲/法甲隐含概率=近似**：因无逐场赔率，其"隐含概率"用诺亚外部赛季基准实际频率代理，故第三节校准表中这三行的"偏差"实为"样本 vs 赛季"差异，**非真实赔率校准**，需明确标注。
3. **西甲无外部实际频率基准**：诺亚仅提供西甲赔率隐含，未给外部实际频率，故代表性检验缺西甲对照；西甲结论置信度低于其他四联赛。
4. **样本小、覆盖非均匀**：单联赛 n=18~40，且仅覆盖特定轮次（如英超 R1/R33/R38）。点估计偏差可达 ±12pp，单联赛结论需谨慎外推到全赛季。
5. **英超赔率仅为单组样本**：overround≈0 源于诺亚捕获的这组特定赔率（2.2/3.98/3.4），不代表英超整体 margin 水平；"margin 系统性高估"结论目前仅西甲单点验证。
