## 一、原始模板数据质量结论
- **数据规模**：3 行 × 8 列（字段：match_id, home, away, league, match_time, odds_win, odds_draw, odds_lose）
- **各列 dtype**：{'match_id': 'str', 'home': 'str', 'away': 'str', 'league': 'str', 'match_time': 'str', 'odds_win': 'float64', 'odds_draw': 'float64', 'odds_lose': 'float64'}
- **缺失值**：全列为 0（缺失率 0.00%）—— 3 行数据本身完整
- **重复行**：0 行；重复 match_id：0 个
- **赔率范围与异常**：win∈[1.85,2.80]、draw∈[3.10,3.40]、lose∈[2.45,3.60]；无 ≤1、负数或 NaN
- **分类异常**：`league` 含 **['世界杯半决赛']**，超出约定 7 类联赛体系（英超, 西甲, 德甲, 意甲, 法甲, 欧冠资格赛, 欧联杯），属脏数据/口径不一致
- **总体结论**：原始文件实为 **3 条**（用户口述为 2 条，可能记忆偏差或文件已更新），但属**模板级空数据**——3 行仅覆盖 2 个比赛日、2 个联赛，无任何真实赛果(result)字段，信息覆盖率极低，无法直接支撑建模，必须先补充演示数据方能做完整画像。

## 二、补充数据生成说明
- **输出文件**：`matches_supplemented.csv`（与原始文件同目录），共 **400 行** × 8 列
- **match_id**：`500_001` ~ `500_400` 顺序编号（字符串，沿用原始下划线格式；编号空间与原始模板独立，切勿跨文件直接按主键合并）
- **真实感约束**：
  - 球队取自英超/西甲/德甲/意甲/法甲真实俱乐部 + 欧冠资格赛/欧联杯欧洲俱乐部，主客队同场不重复；
  - 联赛按权重分布：英超22% / 西甲18% / 德甲16% / 意甲16% / 法甲13% / 欧冠资格赛8% / 欧联杯7%（五大联赛为主）；
  - match_time 落在 2026-07 ~ 2026-12，五大联赛偏周末夜场，欧冠资格赛偏周二/三凌晨，欧联杯偏周四；
  - 赔率由**一致的概率三元组**(p_win,p_draw,p_lose 和为1)经庄家 margin 推出，隐含概率和 1/win+1/draw+1/lose ∈ [1.05,1.12]，赔率三列均落入约定区间；
- **标注方式**：文件同目录附 `README_matches_supplemented.md`，明确声明为「演示/补充数据，非真实比赛结果」。

## 六、核心发现
1. **赔率分布形态合理**：胜赔均值约 2.56、平赔约 3.69、负赔约 3.25，整体呈「胜<平<负」的右偏结构，符合足球赔率常态（主胜概率最高、平局次之、客胜最低）。
2. **联赛高度集中五大联赛**：英超+西甲+德甲+意甲+法甲合计占比约 88.8%，其中英超(25.5%)居首，欧冠资格赛/欧联杯合计约 11.2%，与权重设定一致。
3. **庄家 margin 验证通过**：隐含概率和均值 1.0836、落在 [1.0496, 1.1206]，整体贴合目标区间 [1.05,1.12]，说明赔率由一致概率三元组生成、无内部矛盾（无「明显反序」）。注：因赔率四舍五入至两位小数，有 6 行隐含概率和略微越出 [1.05,1.12]（最小 1.0496、最大 1.1206），偏差均 <0.001，属四舍五入误差，可忽略。
4. **强队/弱队结构健康**：最低赔指向主胜 237 场、客胜 163 场、平局 0 场，客胜为最低赔的占比约 40.8%，反映真实足球中「客队被看好」并非罕见，分布可信。
5. **时令分布合理**：比赛时间集中于 2026-07~2026-12，月度分布见上表，欧冠资格赛/欧联杯多落在深夜与凌晨时段，符合欧洲赛事转播时区特征。

## 七、数据优化建议
- **补充真实赛果字段 `result`**（主胜/平/客胜）与 `score`：当前仅含赔率，无法训练/回测预测模型，这是从「演示」走向「可用」最关键的一步。
- **扩展盘口与上下文字段**：建议增加 `handicap`(让球)、`over_under`(大小球)、`home_rank`/`away_rank`(球队排名)、`home_form`/`away_form`(近期状态) 等，可显著提升金水谣引擎的特征丰富度与预测力。
- **治理原始脏数据**：修正 `league` 中的「世界杯半决赛」等超口径值，统一为 7 类联赛体系；并明确 match_id 跨文件主键策略，避免演示数据与真实模板混淆。
