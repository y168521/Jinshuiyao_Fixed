# Prompt工程技能

## 六大核心技术

### 1. 角色设定（Role）
给AI一个明确的身份和背景，输出会更专业。

**模板**：
```
你是一个【角色】，拥有【多少年/什么级别】的经验，擅长【领域】。
你的说话风格是【风格描述】。
```

**示例**：
> 你是一个有10年经验的Python后端架构师，擅长高并发系统设计。
> 说话直接，给最优解，不绕弯子。

### 2. 任务明确（Task）
把任务说清楚，不要模糊。

**好的**：
> 写一个Python函数，输入一个列表，返回列表中出现次数最多的前3个元素，按出现次数从多到少排序。

**不好的**：
> 写个统计的函数

### 3. 思维链（Chain of Thought）
让AI一步一步思考，复杂问题准确率大幅提升。

**触发方式**：
- "请一步一步思考"
- "先分析问题，再给出答案"
- "你的思考过程是什么？"

**适用场景**：
- 数学题
- 逻辑推理
- 复杂代码
- 多步骤任务

### 4. 少样本学习（Few-shot）
给几个例子，AI就知道你要什么格式。

**示例**：
```
把下面的句子改成更礼貌的说法：

例子1：
输入：把文件发给我
输出：麻烦你把文件发给我一下，谢谢

例子2：
输入：这个方案不行
输出：这个方案可能还有优化空间

现在改这句：
输入：你错了
输出：
```

### 5. 结构化输出
指定输出格式，方便后续处理。

**常用格式**：
- JSON
- Markdown 表格
- 列表
- XML

**示例**：
```
请以JSON格式返回，包含以下字段：
- name: 名称
- description: 描述
- tags: 标签数组

只返回JSON，不要其他文字。
```

### 6. 约束与边界
告诉AI什么不能做，避免跑偏。

**常用约束**：
- 不要超过多少字
- 不要用专业术语
- 只回答问题，不要多余解释
- 如果不知道就说不知道，不要编造

## Prompt 万能公式

```
【角色】 + 【任务】 + 【要求】 + 【输出格式】 + 【示例（可选）】
```

## 不同场景的 Prompt 模板

### 代码生成
```
你是一个资深Python开发工程师。
请写一个【功能描述】的函数。
要求：
1. 有完整的类型注解
2. 有 docstring 说明
3. 处理异常情况
4. 有单元测试示例
输出完整可运行的代码。
```

### 文案写作
```
你是一个有5年经验的文案策划，擅长写种草文案。
请写一篇关于【产品/主题】的小红书文案。
要求：
- 标题吸引人，带emoji
- 正文分点，口语化
- 有真实感，像朋友分享
- 300字以内
```

### 数据分析
```
你是一个数据分析师。
我有一份数据，描述如下：【数据描述】
请帮我分析：【分析目标】
要求：
1. 先给出核心结论
2. 再给出分析过程
3. 最后给出建议
```

## 常见问题与优化

### AI 回答太啰嗦
- 加一句："直接给答案，不要多余解释"
- "精简到3句话以内"

### AI 编造信息（幻觉）
- 加："如果你不确定，就说不知道，不要编造"
- 要求给出信息来源
- 提供参考资料让AI基于资料回答

### AI 输出格式不对
- 给一个完整的示例
- 明确说"只返回xxx，不要其他内容"
- 用"输出格式："单独一段说明

### 复杂任务做不好
- 拆成多步，一步步来
- 先让AI做计划，确认了再执行
- 每一步检查结果，再做下一步
