# 法律文书写作技能

## 重要声明
本技能提供的模板和建议仅供参考，不构成法律意见。重要合同建议咨询专业律师。

## 通用写作原则

### 1. 信息准确完整
- 当事人姓名/名称、身份证号必须准确
- 地址、联系方式写清楚
- 金额、日期、数量等数字必须大写+小写双重标注

### 2. 表述明确无歧义
- 不用「大概」「左右」「尽快」这类模糊词
- 时间、金额、标准必须量化
- 一词一义，同一个概念全程用同一个词

### 3. 权利义务对等
- 不能只写对方的义务，不写自己的
- 违约责任双方都要有

### 4. 争议解决写清楚
- 管辖法院：约定在哪打官司
- 还是仲裁：一裁终局，效率高但费用高

## 常用文书模板

### 1. 借条
```
借条

今借到【出借人姓名】（身份证号：XXX）人民币【大写金额】元整（¥小写金额），
借款期限：自【起始日期】至【结束日期】。
利息约定：【年利率X% / 无息】。
还款方式：【到期一次性还本付息 / 按月付息到期还本】。

如逾期未还，按每日【X‰】支付违约金，并承担出借人为维权产生的律师费、诉讼费等全部费用。
争议由出借人所在地人民法院管辖。

借款人（签字按手印）：
身份证号：
联系电话：
日期： 年 月 日

附：借款人身份证复印件正反面
```

**注意**：
- 必须写「今借到」，不是「今借」
- 金额大写：零壹贰叁肆伍陆柒捌玖拾佰仟万亿
- 大额借款一定要银行转账，备注「借款」
- 利息：年利率不超过LPR的4倍才受法律保护

### 2. 房屋租赁合同
```
房屋租赁合同

出租方（甲方）：姓名 身份证号 电话
承租方（乙方）：姓名 身份证号 电话

一、房屋基本情况
甲方将位于【详细地址】的房屋出租给乙方使用。

二、租赁期限
自【开始日期】至【结束日期】，共【X】个月。

三、租金及支付方式
月租金人民币【大写】元（¥小写）。
支付方式：【押一付三 / 月付】，每期提前7天支付。
押金：人民币【X】元，合同期满无损坏无息退还。

四、相关费用
租赁期间，【水费/电费/燃气费/物业费/网费】由乙方承担。

五、双方权利义务
1. 甲方保证房屋及设施正常可用
2. 乙方不得擅自改造、转租，不得从事违法活动
3. 乙方应爱护房屋设施，人为损坏照价赔偿

六、违约责任
1. 乙方逾期付租，每日按应付金额的【X%】付违约金
2. 甲方提前收房 / 乙方提前退租，需提前【30】天通知，并支付【1个月租金】作为违约金

七、争议解决
协商不成，向房屋所在地人民法院起诉。

甲方签字：          乙方签字：
日期：              日期：
```

### 3. 授权委托书
```
授权委托书

委托人：姓名 性别 身份证号 联系电话
受托人：姓名 性别 身份证号 联系电话

委托人因【原因】，无法亲自办理【具体事项】，
特委托【受托人姓名】作为我的合法代理人，全权代表我办理以下事项：

1. 【具体权限1】
2. 【具体权限2】
3. 【具体权限3】

委托期限：自【开始日期】至【结束日期】。
受托人在上述权限范围内签署的文件，我均予以认可，承担相应法律责任。
受托人【有/无】转委托权。

委托人（签字按手印）：
日期： 年 月 日

附：委托人和受托人身份证复印件
```

**注意**：
- 权限写具体，别只写「全权委托」
- 重要事项建议做公证委托

### 4. 保密协议（NDA）
```
保密协议

甲方：
乙方：

鉴于双方就【合作事项】进行沟通接触，可能接触到对方的保密信息，双方约定：

一、保密信息范围
包括但不限于：技术资料、商业数据、客户信息、财务数据、合作方案等未公开信息。

二、保密义务
1. 仅用于本次合作评估目的，不得用于其他用途
2. 采取合理措施保密，不得向第三方泄露
3. 仅限必要人员知悉

三、保密期限
自接触之日起【X】年。合作不成不影响保密义务。

四、违约责任
违约方赔偿守约方因此造成的全部损失。

五、争议解决
协商不成，向甲方所在地人民法院起诉。

甲方签字/盖章：      乙方签字/盖章：
日期：              日期：
```

## 签署注意事项

### 个人签署
- 必须本人签字，不能代签（有授权除外）
- 按手印：右手食指，按在签名上
- 重要文件最好有见证人

### 公司签署
- 盖公章（效力最高）
- 法定代表人签字，或有授权的人签字

### 份数与留存
- 至少一式两份，双方各执一份
- 都要原件，复印件效力弱
- 重要文件建议拍照/扫描存档

## 常见坑点提醒

### 1. 口头协议不算数
重要的事一定要写下来，口头约定举证难。

### 2. 身份证号不能少
只有姓名没有身份证号，起诉时被告身份不明确立不了案。

### 3. 管辖约定很重要
没约定的话一般要到被告所在地打官司，异地很麻烦。

### 4. 借条 vs 欠条不一样
- 借条：因借款产生，诉讼时效从还款到期日算3年
- 欠条：因其他原因产生，诉讼时效从出具欠条日算3年
- 借钱一定要写「借条」，别写「欠条」
