# AI音乐全链路创作技能

## 六边形创作框架
1. **叙事性**：有故事、有画面、有情感
2. **记忆点**：副歌洗脑、旋律抓耳
3. **反差感**：风格碰撞、情绪转折
4. **具象化**：用具体物象代替抽象抒情
5. **韵律感**：韵脚统一、节奏舒服
6. **共鸣点**：戳中普遍情绪

## 核心风格模板

### 1. 叙事民谣
- BPM：70-90
- 配器：木吉他、口琴、轻鼓点
- 特点：讲故事、画面感强、情感真挚
- 代表：《成都》《董小姐》

### 2. 国风仙曲
- BPM：80-100
- 配器：古筝、笛子、二胡、弦乐
- 特点：意境唯美、歌词古典、仙气飘飘
- 代表：《赤伶》《大鱼》

### 3. 复古Disco
- BPM：110-128
- 配器：合成器、贝斯、鼓机
- 特点：动感洗脑、复古质感、适合跳舞
- 代表：《野狼Disco》《霓虹甜心》

### 4. Trap Rap
- BPM：140-160
- 配器：808贝斯、Hi-Hat、电子鼓
- 特点：节奏强劲、态度鲜明、flow多变
- 代表：各类说唱热门曲

## 歌词创作方法论

### 爆款拆解仿写法
1. 找一首同风格爆款
2. 拆解结构：主歌/预副/副歌/桥段
3. 拆解韵脚：押什么韵、怎么转韵
4. 拆解意象：用了哪些物象
5. 保留骨架，替换内容

### 反差感神曲公式
- 深情旋律 + 方言吐槽
- 古风编曲 + 现代歌词
- 温柔女声 + 硬核内容
- 欢快节奏 + 悲伤内核

## 结构化质检清单（Checklist）
- [ ] 韵脚统一，不杂乱
- [ ] 每段都有具体物象，不空泛
- [ ] 副歌有记忆点，能哼出来
- [ ] 有反差/转折，不平铺直叙
- [ ] 桥段有升华，不重复
- [ ] 金句独立成句，可传播

## AI生成参数模板

### Suno 参数
- 风格标签：明确写清风格+配器+BPM
- 情绪：欢快/悲伤/治愈/燃
- 人声：男/女、音色特点
- 结构：[Verse][Chorus][Bridge]

### Udio 参数
- prompt 分段：歌词 + 风格描述分开
- 扩展：用extend功能加长
- 混音：自动/自定义
