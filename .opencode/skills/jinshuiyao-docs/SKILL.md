## JS 编号规则

- 格式：`JS-YYYYMMDD-序号`，如 `JS-20260802-04`
- 登记前先 grep 总索引里最新编号，避免冲突（F4 历史坑）
- 一个会话的多个任务可共用一个 JS 编号，但交接中心里**每任务独立一行**（W 编号递增）

## 完成一个任务的固定动作（铁律 0 五步）

1. **登记交接中心**：追加一行 `| Wxx | 标题 日期 | opencode | 已完成 | 干了什么+验证结果+⚠️注意 | JS-编号 |`（W 编号先查最后一行递增）
2. **登记总索引**：汇总表加一行 + 明细区加 `### JS-编号` 详细条目（任务/落地/验证/被否决/未做/关联/成熟度）
3. **经验当场写**：有价值的坑/方法 → 经验收集箱当天新条目（`## 日期 第几条：标题`）
4. **立即提交**：攒够 2 个任务就 `git add` + commit（`docs: 登记...`）+ push，不等收工
5. **30 秒复查**：`git status` 有无遗留未提交源码，有就补交

## 交接中心 W 编号格式（参照）

```
| W63 | 标题 日期 | opencode | 已完成 | 落地详情(含验证/⚠️注意) | JS-编号 |
| W63补 | 补充任务 | ... | 完成 | 详情 | JS-编号 |
```

## 经验收集箱条目标准结构

```
## YYYY-MM-DD 第N条：标题
- **问题**：...
- **根因**：...
- **处理**：...
- **教训/规则**：...
- **知识成熟度**：verified（实测过）或 theoretical（未实测）
- **关联总索引**：JS-编号 / 交接中心 W编号
```

## 收工强制动作（完整版）

1. 更新交接中心已完成表
2. 追加经验收集箱
3. `py -3.14 tools/gate.py --check`（全绿=完成）
4. 总索引登记一条
5. `py -3.14 tools/ops.py --close`
6. `git commit` 入库（pre-commit 自动记录）
