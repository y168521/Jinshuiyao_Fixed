# 专业文案写作技能

## 核心原则
1. **用户视角**：不说「我有什么」，说「对你有什么用」
2. **卖点具象化**：不说「效果好」，说「7天淡斑、28天提亮」
3. **一句话原则**：核心信息必须一句话说清楚
4. **AIDA 模型**：注意 → 兴趣 → 欲望 → 行动

## 标题创作

### 标题六大黄金公式

#### 1. 数字型
- 「3个技巧，让你的歌词记忆点翻倍」
- 原理：数字具体、有确定感

#### 2. 疑问型
- 「为什么你的歌总是不抓耳？」
- 原理：戳中痛点，引发好奇

#### 3. 对比型
- 「同样是写歌词，为什么他的能火？」
- 原理：制造反差，激发好奇心

#### 4. 利益型
- 「学会泊松模型，足彩预测准确率提升30%」
- 原理：直接给好处

#### 5. 悬念型
- 「做了3年数据分析，我发现了一个反常识的规律」
- 原理：话说一半，用户想点开看

#### 6. 紧急型
- 「最后3天，错过再等一年」
- 原理：制造稀缺感，促进行动

## 卖点提炼

### FABE 法则
- **Feature 特征**：产品是什么
- **Advantage 优势**：比别人好在哪里
- **Benefit 利益**：对用户有什么用
- **Evidence 证据**：怎么证明

**重点**：用户不关心 Feature，只关心 Benefit。

### 痛点 vs 爽点
- **痛点文案**：戳问题 → 给方案
- **爽点文案**：画蓝图 → 给路径

## 不同类型文案写作

### 1. 产品介绍文案
**结构**：
1. 一句话价值主张
2. 核心卖点（3个以内）
3. 适用人群
4. 效果证明
5. 行动号召

### 2. Slogan / 品牌口号
**标准**：
- 短：4-12个字
- 顺：朗朗上口
- 准：说清核心价值
- 独：有辨识度

### 3. 种草软文
**三段式结构**：
1. 场景代入：讲一个用户熟悉的场景/痛点
2. 解决方案出场：自然带出产品
3. 效果展示+行动号召

**要点**：
- 像朋友分享，不像硬广
- 有具体细节，真实可信
- 有对比（用之前 vs 用之后）

### 4. 广告文案（短文案）
**公式**：痛点 + 方案 + 行动

## 文案优化方法

### 自检清单
- [ ] 第一句能不能抓住注意力？
- [ ] 用户能不能快速看懂？
- [ ] 有没有说清楚对他的好处？
- [ ] 有没有具体的细节和证据？
- [ ] 最后有没有告诉他该做什么？

### 删废话
- 去掉「非常」「十分」这类副词
- 去掉「我们认为」「大家都知道」这类套话
- 每删一个字，文案力量就强一分

### 具体化
- ❌ 「速度很快」
- ✅ 「导入1000条数据只需要0.3秒」

**原则**：能用数字就不用形容词。

### A/B 测试
- 同一个内容写两个版本
- 小范围测试哪个效果好
- 用数据说话，不靠感觉

## 不同平台文案特点

| 平台 | 特点 | 写作要点 |
|------|------|----------|
| 公众号 | 深度阅读 | 标题要勾人，内容有干货 |
| 小红书 | 种草 | 标题带emoji，分点清晰 |
| 抖音 | 短平快 | 开头直接抛问题，口语化 |
| 官网 | 专业信任 | 价值主张清晰，案例证明 |

## 常见文案病

### 1. 自嗨型
- 表现：通篇说「我们很厉害」
- 药方：换成「对你有什么用」的视角

### 2. 空洞型
- 表现：全是形容词，没有具体信息
- 药方：每个形容词都换成数字或事实

### 3. 没行动型
- 表现：看完不知道该干嘛
- 药方：结尾明确告诉用户下一步做什么
