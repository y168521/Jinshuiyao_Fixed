# 车辆交通事务指南技能

## 违章处理

### 查询渠道
1. 交管12123 APP（最权威）
2. 各地交警微信公众号
3. 支付宝/微信城市服务

### 处理方式
- **12123在线处理**：6分以下、200元以下可直接在线处理扣分+缴费
- **交警队窗口处理**：需带驾驶证、行驶证、身份证
- **银行/自助机缴费**：拿到处罚决定书后去银行或自助机缴费

### 注意事项
- 违章后15天内处理，逾期有滞纳金（不超过本金）
- 记分周期：从驾驶证领证日期算起，12个月一个周期
- C1驾照实习期：扣11分以内没事，扣12分注销驾照

## 二手车交易

### 买二手车检查清单
1. **外观**：车漆色差、钣金痕迹（看胶条）、玻璃日期
2. **发动机舱**：螺丝拧动痕迹、漏油、线束老化
3. **内饰**：磨损程度、安全带有无更换痕迹
4. **底盘**：托底痕迹、漏油、悬挂
5. **手续**：登记证书（绿本）、行驶证、保险单、购置税本
6. **试驾**：起步、刹车、转向、异响

### 过户流程
1. 开二手车交易发票
2. 验车（拓号、照相）
3. 选号（现场50选1或自编）
4. 拿新行驶证、登记证书变更
5. 保险过户

### 卖车注意
- 一定要过户，别只签协议
- 过户前处理完所有违章
- 保险同步过户，不然出事麻烦

## 车辆报废

### 报废标准
- 行驶里程60万公里引导报废
- 年检不合格强制报废
- 排放标准不达标（如国三以下限行）

### 报废流程
1. 准备材料：行驶证、登记证书、车主身份证
2. 送到报废厂
3. 开具报废证明
4. 车管所注销
5. 拿报废补贴（如有）

### 注意
- 不要私自卖废铁，一定要走正规报废
- 不报废会影响新车上牌
- 违章也要处理完才能报废

## 保险理赔

### 理赔流程
1. 报案（保险公司电话）
2. 定损（保险公司派人或去定损中心）
3. 修车（自己先垫付或直赔）
4. 拿发票报销

### 常见险种
- **交强险**：强制，赔对方，额度低
- **三者险**：赔对方，建议至少100万
- **车损险**：赔自己车
- **不计免赔**：全额赔付，不打折

### 不出险更划算
- 一年不出险，次年保费打折
- 小刮小蹭自己修可能更划算
- 出险次数影响下三年保费

## 常见车型维护

### 老马自达3（经典款）
- 常见问题：气门室盖垫漏油、机脚胶老化抖动
- 保养：机油5W-30，5000公里一换
- 易损件：刹车片、火花塞、正时皮带（10万公里换）

### 丰田雅力士
- 特点：省油、耐造、毛病少
- 保养：机油0W-20，1万公里一换
- 常见问题：气门室盖垫渗油（正常，不用修）

### 通用保养周期
- 机油机滤：5000-10000公里
- 空气滤芯：1-2万公里
- 汽油滤芯：4-6万公里
- 变速箱油：6-8万公里
- 刹车片：3-5万公里（看驾驶习惯）
- 轮胎：5年或6万公里
