# 数据可视化设计技能

## 核心原则
1. **准确优先**：先保证数据传达准确，再谈美观
2. **减少噪音**：去掉一切不承载信息的装饰元素
3. **一图一义**：每张图表只讲一个核心信息
4. **用户视角**：看的人关心什么，就展示什么

## 图表选型指南

### 按目的选图

#### 1. 对比类 → 柱状图 / 条形图
**适用**：不同类别之间的数值比较
- 类别少于10个用柱状图
- 类别多长文本用横向条形图

#### 2. 趋势类 → 折线图
**适用**：随时间变化的趋势
- 多系列对比用多条折线，不超过4条
- X轴必须是有序的（时间、期数）

#### 3. 占比类 → 饼图 / 环形图
**适用**：整体的各部分占比
- 分类不超过5个
- 慎用3D饼图，会扭曲比例

#### 4. 分布类 → 直方图 / 热力图
**适用**：数据的分布密度
- 和值分布区间 → 直方图
- 两位号码组合频次 → 热力图

#### 5. 进度类 → 进度条
**适用**：完成度、达成率
- 纯装饰性的仪表盘少用

#### 6. 多维对比 → 雷达图
**适用**：多个维度同时对比
- 维度5-8个最合适

### 常见错误
- ❌ 用饼图做对比（各部分加起来不是100%）
- ❌ 用折线图看分类对比（X轴无序）
- ❌ Y轴不从0开始（柱状图会放大差异）
- ❌ 颜色太多，分不清谁是谁
- ❌ 3D效果，干扰数据读取

## 配色方案

### 配色基本原则
1. 不超过6种颜色
2. 同一系列用同色系深浅
3. 重点数据用强调色，其他用中性色
4. 考虑色盲友好，避免红+绿组合

### 推荐配色方案

#### 方案1：商务深色主题（数据大屏风）
```
主背景：#0F172A 深蓝灰
卡片背景：#1E293B
主色：#3B82F6 亮蓝
辅助色1：#10B981 绿
辅助色2：#F59E0B 橙
辅助色3：#EF4444 红
文字主色：#F1F5F9
文字次色：#94A3B8
```

#### 方案2：清爽浅色主题（后台系统风）
```
背景：#F8FAFC
卡片：#FFFFFF
主色：#2563EB 蓝
系列色：#2563EB / #10B981 / #F59E0B / #8B5CF6 / #EC4899
文字：#1E293B / #64748B
边框：#E2E8F0
```

### 数据配色技巧
- 有序数据：同一颜色深浅变化
- 分类数据：不同色相区分
- 强调数据：一个亮色+其他灰色
- 正负值：绿涨红跌（国内习惯）

## 仪表盘布局设计

### 经典布局结构
```
┌─────────────────────────────────────────────┐
│  顶部：标题 + 筛选条件 + 关键指标卡片         │
├──────────┬──────────┬──────────┬────────────┤
│ 指标卡1   │ 指标卡2   │ 指标卡3   │ 指标卡4    │
├──────────┴──────────┴──────────┴────────────┤
│                                             │
│           主图表区域（最大的图）              │
│                                             │
├──────────────────────┬──────────────────────┤
│                      │                      │
│      次图表1         │      次图表2         │
│                      │                      │
└──────────────────────┴──────────────────────┘
```

### 布局原则
1. 重要的放上面、放左边
2. 相关的放一起
3. 对齐统一，间距一致
4. 留白呼吸，别塞太满

### 指标卡片设计
```
┌─────────────────┐
│  总期数          │  ← 标签（小字，灰色）
│                 │
│  1,256          │  ← 大数字（主色，加粗）
│                 │
│  ↑ 12 本周新增   │  ← 趋势（小字，带箭头）
└─────────────────┘
```

## 可读性优化

### 图表去噪
- 去掉不必要的网格线，或改成浅灰色
- 去掉3D效果、阴影、渐变装饰
- 图例放合适位置，别挡数据
- Y轴标签不要太密

### 交互优化
- 鼠标悬停显示详细数据（tooltip）
- 点击图例可以显示/隐藏对应系列
- 数据量大加缩放拖动（dataZoom）
- 多图联动

## 数据故事化

### 怎么用图表讲故事
不要把数据堆上去就完事，要有叙事逻辑：

#### 结构1：总 → 分
1. 先给结论（总览数字、核心趋势）
2. 再展开细节（分维度拆解）
3. 最后给异常点/重点提醒

#### 结构2：是什么 → 为什么 → 怎么办
1. 展示现状
2. 分析原因
3. 给出建议

### 重点突出技巧
- 异常值用不同颜色标红
- 关键数据加标注线
- 用注释文字直接点出结论
- 不重要的数据灰掉

### 避免误导
- Y轴从0开始（柱状图必须）
- 饼图各部分加起来100%
- 时间轴间隔均匀
- 对比用相同的刻度标准

## 彩票数据系统可视化示例

### 首页仪表盘
1. 顶部指标卡：总期数、本期形态、当前遗漏、最热号码
2. 主图：近100期和值走势折线图
3. 左下：号码冷热柱状图
4. 右下：形态占比环形图

### 号码分析页
1. 百位/十位/个位 频次柱状图（三图并排）
2. 012路分布饼图
3. 遗漏值排行榜（条形图）
4. 和值分布直方图

## 设计检查清单
- [ ] 图表类型选对了吗
- [ ] 颜色不超过6种且区分度够吗
- [ ] 有没有多余的装饰元素可以删掉
- [ ] 文字大小层级清晰吗
- [ ] 关键信息一眼就能看到吗
- [ ] 有没有可能误导读者的地方
