# 彩票数据分析与预测系统技能

## 适用场景
- 数字彩（福彩3D、排列三、双色球、大乐透）数据分析
- 号码形态识别（组三/组六/豹子、大小、奇偶、012路）
- 冷热号分析、遗漏值计算、趋势预测
- 足彩胜平负预测、泊松分布建模
- 投注方案优化、2串1/3串1组合策略

## 数字彩核心分析方法

### 1. 形态分析
- **大小形态**：大号(5-9) vs 小号(0-4)
- **奇偶形态**：奇数 vs 偶数
- **012路形态**：除3余数分类
- **跨度**：最大号 - 最小号
- **和值**：三个号码之和
- **组三/组六/豹子**：号码重复情况

### 2. 冷热分析
- 热号：近10期出现3次以上
- 温号：近10期出现1-2次
- 冷号：近10期未出现
- 计算公式：出现次数 / 总期数

### 3. 遗漏值分析
- 当前遗漏：连续未出现期数
- 平均遗漏：历史平均间隔
- 最大遗漏：历史最长间隔
- 回补概率：根据遗漏程度判断

## 足彩泊松预测模型

### 核心公式
- λ（lambda）= 预期进球数
- P(X=k) = (λ^k * e^(-λ)) / k!

### 计算步骤
1. 计算两队历史平均进球/失球
2. 计算联赛平均进球数
3. 计算进攻强度和防守强度
4. 得出各自预期进球数 λ1, λ2
5. 用泊松分布计算各比分概率
6. 汇总胜平负概率

## 投注策略

### 2串1优化
- 选择两场胜率60%以上的比赛
- 组合后胜率约36%
- 赔率需在2.8以上才有正期望

### 资金管理
- 单注不超过总资金的2%
- 倍投有风险，慎用
- 长期统计期望，不看单次结果
