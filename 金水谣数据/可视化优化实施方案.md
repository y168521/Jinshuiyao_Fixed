## 第二阶段：前端重构（建议 Qoder）

### 2.1 走势图懒加载
- `trend-charts.js` 从 `window.TREND_DATA` 全局变量 → 按 Tab 点击 `fetch(/api/trend/data?lot=...)` 按需拉取
- 首次加载时先占位 loading，Tab 切换时懒加载对应图表
- 前端缓存：已加载的彩种存 `sessionStorage`，同一次会话不再重复请求
- 参考：ECharts 大数据优化文「分片加载 + appendData 增量渲染」

### 2.2 新鲜度 UI
- 更新时间从客户端 `new Date()` → 服务端返回的 `generated_at` 时间戳
- 陈旧数据黄色告警（>1440 分钟暗淡标记）

### 2.3 图表库收敛
- Chart.js（lottery_dashboard.html）→ 迁移到 ECharts
- Plotly（lottery_visualization.html）→ 迁移到 ECharts
- matplotlib GUI 走势图 → 可选的 ECharts 轻量替换

### 2.4 错误兜底
- 图表区域捕获 API 异常 → 显示缓存版本 / 兜底文字
- 遵循 easyv.cloud "核心数据库中断→直接黑屏" 失败教训

## 第三阶段：交互增强（建议 Qoder/TRAE）

### 3.1 钻取与联动
- 点击图表期号 → 弹窗显示该期开奖细节（`/api/lottery/history?period=XXX`）
- 日期范围筛选器联动全部图表

### 3.2 大盘彩种图表补全
- 双色球/大乐透新增：蓝球走势、和值分布、奇偶比、AC 值
- `TrendGenerator` 增加 `_blue_ball_trend`、`_sum_value_chart` 等方法

### 3.3 预测可视化增强
- 预测结果加置信度条形图、历史命中率对比折线

### 3.4 设计统一
- 赛博朋克量化面板 → 逐步迁移到深海熔金统一主题
- 浅色 review-dashboard → 可选深海熔金深色版
