🛟 DeepSeek 备用代码助手 · 图文使用说明

当 TRAE、WorkBuddy 用不了时，也能靠 DeepSeek 改代码。双击即用，全程中文，专为不熟悉电脑的朋友设计。

1准备一个 DeepSeek API Key

这是什么：相当于一把"钥匙"，让程序能请 DeepSeek 帮你改代码。第一次需要去官网免费拿一把。
怎么拿：打开 platform.deepseek.com，注册 / 登录 → 右上角「API Keys」→ 创建密钥 → 复制那串 sk-... 开头的文字。
保存密钥已保存
提示：密钥只保存在你这台电脑上，只发给 DeepSeek，不会给别人。
⚠️ 密钥不要发给陌生人；本工具只在你自己的电脑上用。

2双击启动（一步打开）

进入文件夹 Jinshuiyao_Fixed → AI代码助手(DeepSeek备用)
双击 启动DeepSeek助手.bat，会弹出黑窗口并自动打开浏览器。
🚀 启动DeepSeek助手.bat → 自动打开浏览器页面
浏览器打开的地址通常是 http://127.0.0.1:18890/（若被占用会自动换端口，以黑窗口里显示的为准）。
黑窗口不要关，关了助手就停了。用完按 Ctrl+C 或关窗口即可。

3第一次用：填写并保存密钥

在网页「第 1 步」的输入框里粘贴你的 sk-... 密钥，点 保存密钥。
右侧状态变成绿色「已保存」就成功了。之后每次打开都不用再填。
保存密钥已保存

4粘贴代码 + 写要求，点提交

修改要求：用大白话写你想干什么。例如："给这段代码加中文注释，并优化运行速度"。
代码：把代码粘进框里；或点「选择文件」直接加载本地代码文件。
模型：默认用 deepseek-chat（快）；难题可换 deepseek-reasoner（慢但更会想）。
点 🚀 提交修改，稍等几秒，结果出现在下方。
🚀 提交修改

5复制 / 下载结果

结果框里是改好的完整代码。
点 复制结果 直接贴到你的文件里；或点 下载为 .txt 存成文件。
复制结果 下载为 .txt

6网络不好也不怕：待重试队列

如果提交时断网 / 超时，任务会自动存进队列，不会丢。
网络恢复后，点「重试待处理任务」就能把积压的活一次性补跑。
正常提交成功后，助手也会顺手补跑之前排队的任务。
🔄 重试待处理任务 重试 2 个，成功 2 个，剩余 0 个
背后机制：每个请求最多重试 5 次，失败间隔自动变长（1秒→2秒→4秒…），并在两个接口地址间切换，最大限度扛住网络抖动。

7进阶：命令行方式（可不用）

熟悉命令行的朋友，可以在该文件夹里打开终端，直接跑：
python deepseek_coder.py --file 你的文件.py --instruction "优化性能" --out 结果.txt
加 --backup 会自动把原文件备份成 你的文件.py.bak。

★常见问题

  • 黑窗口一闪通常是没装 Python。请安装 Python 3.8+，安装时勾选 "Add to PATH"。
  • 提示密钥无效检查 sk-... 是否复制完整、有无多余空格；到 DeepSeek 后台确认密钥未被删除。
  • 一直转圈 / 超时网络不稳。任务已进队列，等网络好点再点「重试待处理任务」。
  • 浏览器没自动打开手动在地址栏输入黑窗口里显示的地址（如 http://127.0.0.1:18890/）。
  • 想换电脑用把整个 AI代码助手(DeepSeek备用) 文件夹拷走即可，无需安装。
本工具纯本地运行（127.0.0.1），无需联网安装任何包；仅在调用 DeepSeek 时才访问网络。与主项目的 TRAE / WorkBuddy 流程互不干扰。
