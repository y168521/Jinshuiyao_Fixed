金水谣万物预测引擎 · 对比全网优秀模型差距分析与补充方案

分析日期：2026-07-18 ｜ 分析对象：Jinshuiyao_Fixed（约 67,000 行 Python，6 大预测域）｜ 参照基准：2026 年生产级时序/预测系统 SOTA
结论速览：金水谣的在「工程治理」（多域编排、自愈启动、审计、监控、知识库、726 测试）上已相当成熟； 但在「建模方法论」上与 2026 年全网优秀模型存在代差——它仍以手工启发式 + 遗传规则进化为主， 缺少预训练时序基础模型、校准后的不确定性量化、概念漂移检测、集成/堆叠、特征仓库、AutoML、MLOps等能力。 本轮已补齐两块最关键的缺口（已补 共形不确定性 + 概念漂移检测），并给出优先级路线图。

二、2026 全网优秀模型 / 系统能力图谱

① 时序基础模型（TSFM）

  • Chronos-2（Amazon, ~120M）：T5 编解码，零样本强泛化，概率预测
  • TimesFM 2.5（Google, 200M）：patch 解码器，长程强
  • Moirai 2.0（Salesforce, ~11M）：Any-Variate 注意力，原生多变量+协变量，校准分位
  • Time-MoE（50M, MoE）、Granite TTM（~1M, 边缘）、MOMENT（多任务）、Lag-Llama

来源：tsfm.ai 2026 工具包评测、arXiv 农业预测实证（2601.06371）

② 不确定性量化（核心缺口）

  • 共形预测（Conformal Prediction）：分布无关、有限样本覆盖保证的预测区间
  • 变体：Split / Normalized（异方差）/ Adaptive-Online（Gibbs & Candès 2021，分布漂移下长期覆盖）
  • 指标：经验覆盖率、MPIW、Winkler 分数、校准曲线

来源：arXiv 2601.18509；Bohrium / Angelopoulos 教程

③ MLOps 与监控

  • 模型注册表（Model Registry）、实验追踪、版本化产物
  • 概念漂移检测：PSI、KS 检验、CUSUM 控制图
  • 特征仓库（Feature Store）、特征自动生成/选择

④ LLM 智能体预测

  • Time-LLM：冻结 LLM + 重编程对齐，文本/数值/上下文联合建模
  • Agent 循环：预测→解释→复盘，共形集大则转人工兜底
  • AutoML / HPO（Optuna、神经架构搜索）

⚠ 必须诚实声明的底线：彩票的随机性。
双色球、福彩3D 等官方彩票开奖是独立同分布近似的随机过程。在公平机制下，没有任何模型能系统性战胜随机抽奖—— 无论用启发式、深度学习还是时序基础模型，长期命中率都收敛到随机基线。因此：
  • 金水谣真正的价值在工程层（多域编排、自愈、治理、审计、监控、知识库），而非「战胜赔率」。
  • 「模型优化」应聚焦：(a) 诚实的不确定性（让用户知道区间有多宽）、(b) 漂移/校准监控、(c) 对确有统计信号的域（股票趋势、赛事赔率套利）做集成、(d) MLOps 可复现、(e) LLM 智能体解释。
  • 共形模块对彩票的意义：用分布无关的方法量化「无稳定优势」的诚实基线，避免误导性的高置信。

四、本轮已补充的两块能力

1. utils/uncertainty.py — 共形预测不确定性量化 已补

模型无关，纯标准库（无 numpy/scipy 依赖），可在系统 Python 与 venv 双环境运行。包含：

  • SplitConformal：同方差，分位调整法（有限样本覆盖保证）
  • NormalizedConformal：异方差，交叉拟合尺度模型（避免泄漏）
  • AdaptiveConformal：在线/漂移场景，Gibbs & Candès 自适应维持长期覆盖
  • ConformalClassifier：分类预测集合（集合过大→触发保守/人工兜底）
  • 指标：empirical_coverage / mpiw / mean_winkler
自测结果Split 覆盖 0.83 ｜ Normalized 覆盖 1.00 ｜ Adaptive 长期误覆盖 0.138（目标 0.10）｜ 8/8 单测通过

2. core/drift_detector.py — 概念漂移检测器 已补

补齐「数据真实性」之外的「分布漂移」监控。纯标准库。包含：

  • population_stability_index(ref, cur)：PSI（<0.10 无漂移 / 0.10–0.25 中度 / >0.25 重度）
  • ks_test(ref, cur)：两样本 KS 检验（含渐近 p 值）
  • CUSUMDetector：在线残流均值漂移控制图
  • evaluate_drift(ref, cur)：汇总报告 + severity 评级
自测结果同分布 PSI=0.07(p=0.71, low) ｜ 偏移 PSI=6.38(p≈0, high) ｜ CUSUM 持续 +6σ 偏移 39 次告警 ｜ 7/7 单测通过

注：与既有 cache_manager / api_compat / pipeline 等模块一致，二者已通过测试、暂未接入生产路径（预留/验证态），下一步接入见路线图。

五、优先级路线图

P0 · 已交付（本轮）

  • 已补 共形不确定性模块 utils/uncertainty.py
  • 已补 概念漂移检测 core/drift_detector.py

P1 · 建议下一步（接入生产 + 补集成/MLOps）

  • 接入生产路径：将 uncertainty 接入股票域 TechnicalEngine/TrendEngine 产出预测区间；将 drift_detector 接入 prediction_verifier 与每日监控，漂移时推送告警（复用 notifier.py）。
  • 集成/堆叠框架 utils/ensemble.py：对多引擎输出做 out-of-sample 非负最小二乘加权，提升确有信号域的稳健性。
  • 模型注册表 + 实验追踪 core/model_registry.py：JSON 版，记录每次预测的模型版本/参数/区间/覆盖，保证可复现与审计。
  • 校准与诚实基线：为 verifier 增加校准曲线、Brier/CRPS、edge 检测，明确「无稳定优势」基线。

P2 · 中远期（按需、注意依赖与成本）

  • 时序基础模型适配层（可选插件）：以独立可选插件接入 Chronos/TimesFM（需 GPU/较重依赖），用于股票/赛事等有时序结构的域；彩票不推荐。
  • 自动特征工程 / 特征仓库：解耦硬编码特征。
  • AutoML / HPO（Optuna，可选依赖）：超参与架构搜索。
  • LLM 智能体预测解释循环：基于现有 ai_service，把预测+区间+漂移送入智能体生成可读解释与复盘建议。
  • 回测升级：walk-forward + purged & embargoed CV（López de Prado），消除前视偏差。
建议原则：不盲目堆砌「深度学习」——对彩票无意义；把投入放在诚实不确定性、漂移监控、可复现 MLOps、确有信号域的集成上，才是金水谣相对全网优秀模型最有价值的差异化补齐。
