# 金水谣万物引擎 · 部署操作指南

> 适用于 Jinshuiyao_Fixed V23.6 · 更新于 2026-07-19

本文档描述如何在新机器上从零部署金水谣系统。旧版"十二穹武 TS-QW V20.2"的操作步骤已不再适用。

---

## 一、环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11（主要支持） |
| Python | 3.8+（推荐 3.10+），当前主力环境为 D:\python38 |
| 内存 | 4GB+ |
| 磁盘 | 500MB+（含虚拟环境） |
| 网络 | 在线模式需要（调用 DeepSeek API），离线模式不需要 |

## 二、安装步骤

### 步骤 1：安装 Python

如果机器上没有 Python，使用 `程序操作步骤/` 目录中的安装包，或从官网下载：
https://www.python.org/downloads/

安装时务必勾选 "Add Python to PATH"。

### 步骤 2：安装依赖

打开命令行，进入项目目录：

```bash
cd C:\Users\你的用户名\Nutstore\1\我的坚果云\模型\Jinshuiyao_Fixed
pip install -r requirements.txt
```

依赖清单包含 12 个包：requests, beautifulsoup4, numpy, pandas, cryptography, akshare, matplotlib, scipy, customtkinter, openpyxl, lxml, Pillow。

### 步骤 3：配置 API 密钥（可选）

如果需要在线模式（调用 DeepSeek AI 分析）：

```bash
mkdir %USERPROFILE%\.jinshuiyao-secrets
echo sk-你的DeepSeek密钥 > %USERPROFILE%\.jinshuiyao-secrets\deepseek_key.txt
```

注意：密钥文件必须放在 `~/.jinshuiyao-secrets/` 目录中，不要放在项目同步目录内。

### 步骤 4：设置环境变量（可选）

复制 `.env.example` 为 `.env`，按需配置：

```bash
copy .env.example .env
```

常用配置项：
- `TIANSHU_PRELOAD=1` — 启动时自动预加载数据
- `LOG_LEVEL=DEBUG` — 开启详细日志
- `TIANSHU_AI_MODE=offline` — 强制离线模式

## 三、启动系统

### 方式一：双击启动（推荐）

双击 `模型/` 根目录下的 `启动金水谣助手.bat`。

系统会自动：
1. 查找可用的 Python 解释器（优先 venv_314，然后 D:\python38，最后系统 PATH）
2. 清理占用端口 18888 的旧进程
3. 启动 Web 导航服务器
4. 控制台显示访问地址

### 方式二：命令行启动

```bash
cd Jinshuiyao_Fixed

# 完整启动（GUI + 服务器 + 调度器）
python main.py

# 无 GUI 模式（仅服务器 + 调度器）
python main.py --no-gui

# 无调度器模式（仅服务器 + GUI）
python main.py --no-scheduler

# 启用预加载
set TIANSHU_PRELOAD=1 && python main.py
```

### 方式三：启动 DeepSeek 代码助手

```bash
cd Jinshuiyao_Fixed\AI代码助手(DeepSeek备用)
启动DeepSeek助手.bat
```

默认端口 18900（远离导航服务器的 18888-18893 回退区间）。

## 七、常见问题

**Q: 启动时提示"端口被占用"？**
A: launch.bat 会自动清理 18888 端口的旧进程。如果仍被占用，手动执行：
```bash
netstat -ano | findstr :18888
taskkill /F /PID <进程号>
```

**Q: 在线模式提示"API 密钥未配置"？**
A: 确认密钥文件存在于 `%USERPROFILE%\.jinshuiyao-secrets\deepseek_key.txt`，内容仅一行 `sk-xxx`。

**Q: 如何切换在线/离线模式？**
A: 修改 `config/ai_mode.json` 中的 `"mode"` 字段（`online` 或 `offline`），重启生效。也可通过 Web 界面 `/api/ai/mode/set?mode=offline` 切换。

**Q: 运行测试？**
A:
```bash
cd Jinshuiyao_Fixed
python run_tests.py              # 运行全部测试
python run_tests.py --category P0  # 仅运行数据安全测试
python run_tests.py --verbose     # 详细输出
```

**Q: 如何在新设备上恢复运行数据？**
A: 将 `金水谣数据/` 整个目录从旧设备复制到新设备相同位置即可。坚果云同步会自动处理（但 `.nutstoreignore` 已排除了大体积缓存文件，这些需要重新生成）。
