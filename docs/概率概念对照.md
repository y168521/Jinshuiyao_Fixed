## 二、要点说明（易错 4 项）

**#2 Bonferroni（最常踩）**：在 T=4894 次共现检验里，单点 p<0.05 期望出现约 244 次假阳性；不校正会「发现」大量朋友号。校正后阈值 0.05/4894≈1.02e-5，全周期 0 显著。凡「同时跑很多检验」必须校正，否则闸门以全绿姿态失效（类比 JS-20261012-03 假绿）。

**#3 二项方差 vs 泊松**：单个号码在 n 期里的出现次数服从 Binomial(n, p)，方差 = n·p·(1−p)。泊松近似 Var≈np **只在 p 很小时成立**；p 不大时（如均匀性各号 p≈k/N）泊松会系统性低估方差，使 chi/df 偏小、误判「过于均匀」甚至假显著。均匀性卡方必须用二项方差。

**#13 repl 型共现公式**：位置型彩种（福彩3D/排列三/七星彩）每位独立均匀 0–9，数字可重复。两**异**号同现概率用容斥：P(都出现)=1−P(仅缺a)−P(仅缺b)−…=1−2·0.9^P+0.8^P；同号**重复**(≥2 次)用 1−P(0次)−P(1次)=1−0.9^P−P·0.1·0.9^(P−1)。套用 set 型 C(k,2)/C(N,2) 会算错（set 型不放回、不可重复）。

**#17 边际均匀性前提**：共现 z 的零分布假设「各号出现频率均匀」。若数据源本身频数不均（如七星彩 digit1 实测 264 / 期望 161，z=+8.56），共现检验会被边际偏差污染——其 29 个未校正「显著对」全是 digit1 偏多造成的假象，不是朋友号。故共现检验前必须先跑边际均匀性闸门，不均则整 field 排除，不可直接报显著。
