## 二、要点说明（易错 4 项）

**#2 Bonferroni（最常踩）**：在 T=4894 次共现检验里，单点 p<0.05 期望出现约 244 次假阳性；不校正会「发现」大量朋友号。校正后阈值 0.05/4894≈1.02e-5，全周期 0 显著。凡「同时跑很多检验」必须校正，否则闸门以全绿姿态失效（类比 JS-20261012-03 假绿）。

**#3 二项方差 vs 泊松**：单个号码在 n 期里的出现次数服从 Binomial(n, p)，方差 = n·p·(1−p)。泊松近似 Var≈np **只在 p 很小时成立**；p 不大时（如均匀性各号 p≈k/N）泊松会系统性低估方差，使 chi/df 偏小、误判「过于均匀」甚至假显著。均匀性卡方必须用二项方差。

**#13 repl 型共现公式**：位置型彩种（福彩3D/排列三/七星彩）每位独立均匀 0–9，数字可重复。两**异**号同现概率用容斥：P(都出现)=1−P(仅缺a)−P(仅缺b)−…=1−2·0.9^P+0.8^P；同号**重复**(≥2 次)用 1−P(0次)−P(1次)=1−0.9^P−P·0.1·0.9^(P−1)。套用 set 型 C(k,2)/C(N,2) 会算错（set 型不放回、不可重复）。

**#17 边际均匀性前提**：共现 z 的零分布假设「各号出现频率均匀」。若数据源本身频数不均（如七星彩 digit1 实测 264 / 期望 161，z=+8.56），共现检验会被边际偏差污染——其 29 个未校正「显著对」全是 digit1 偏多造成的假象，不是朋友号。故共现检验前必须先跑边际均匀性闸门，不均则整 field 排除，不可直接报显著。

## 四、全网检索补充：认知偏误与方法论误用（防御清单）

> 2026-10-12 全网检索（彩票概率谬误 / 统计误用 / 认知偏误列表）补充。**非本仓逐期实测概念**，而是让「民间规律 / 朋友号 / 冷热号」**感觉真实、实为错觉**的认知与方法论根源。写任何选号/复盘结论前先自查是否踩了其中一条。每条指回 §一 的实测概念，说明它如何为假显著背书。

| # | 概念 | 正确认知 / 做法 | 常见错觉（对照） | 关联 |
|---|---|---|---|---|
| S1 | 赌徒谬误 Gambler's Fallacy | 每期独立，连黑 10 次后下一期红的概率仍 = P(红)；硬币/轮盘无记忆 | 「连出 N 期黑，红该出了」——把大数定律误当短期修正力 | #10 冷热号心理根 |
| S2 | 热手谬误 Hot Hand Fallacy | 纯随机系统无热手，连中后下一注中奖概率不变 | 「最近热号会延续」——与赌徒谬误相反的错误 | #10 |
| S3 | 数据捕捞 p-hacking / 钓鱼 | 无预设假设遍历数据找显著属非法；假设须用**独立数据**二次验证 | 在 4894 对里挑「看起来显著」的当规律报道 | #2 Bonferroni 的方法论根因 |
| S4 | 德州神枪手谬误 Texas Sharpshooter | 先有数据再画靶=循环论证；须预注册假设再验 | 在随机开奖序列里「发现」某形态当预测规律 | #11 邻号偏移「只看近 30 期偶然」 |
| S5 | 小数定律 / 聚类错觉 | 小样本变异远大于直觉，随机会自然成簇 | 把短窗聚集当「热号 / 冷号信号」 | #10 / #7 |
| S6 | 回归均值 Regression to Mean | 极端观测后更易回到均值，是统计现象非规律 | 「冷号该反弹了」=把回归均值当因果 | 新 |
| S7 | 基础比率谬误 Base Rate Fallacy | 须用总体频率（中奖基数）而非个案；贝叶斯更新 | 误读「某号中奖概率」忽略基础中奖率 | #7 命中率基线 |
| S8 | 检察官谬误 Prosecutor's Fallacy | 条件概率不可倒置：「证据给定无罪」的概率 ≠ 「无罪给定证据」的概率 | 「某形态历史命中率高」误当「下一期该中」 | #14 转移独立性 |
| S9 | 辛普森悖论 Simpson's Paradox | 分组趋势合并后可能反转；合并彩种/子群须分层 | 跨彩种合并出的「规律」实为分层混淆 | 合并分析警示 |
| S10 | 控制错觉 Illusion of Control | 自选号 / 幸运仪式不影响纯随机结果 | 「我选的号更可能中」——把可控感当预测力 | 业务心理 |

**与 §一 的关系**：S1/S2/S5/S6 是 #10 冷热号「看似有效」的心理来源；S3 是 #2 多重比较必须 Bonferroni 的**行为根因**（不校正=数据捕捞）；S4 是 #11 邻号偏移只信近窗偶然的形态学根因；S7/S8 是 #7/#14 条件概率误读的根因。即：§一 用统计检验证伪了规律，§四 解释人为何仍坚信规律——两者互补，核心结论不变：**彩票无预测力，任何选号策略固定奖期望完全相同**。
