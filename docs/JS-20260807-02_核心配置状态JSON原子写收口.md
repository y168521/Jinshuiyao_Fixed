## 1. 背景（为什么是这一刀）

- 其中 `free_model_pool.py`、`gui_registry.py` 还用 `except: pass` **静默吞错**，故障时无声无息。

## 4. 契约与安全约束

- `safe_write_json(embed_checksum=False)` 时**不会**给业务数据注入 `_metadata`（契铁律），且会剥离残留旧 checksum → 读侧兼容旧格式，**不破坏现有文件**。
- 输出格式保持 `ensure_ascii=False, indent=2`，与原 `json.dump` 一致，diff 友好。
- 迁移后 `import json` 仅在仍被其他代码使用处保留（free_model_pool/ai_service/theme_manager/model_shadow 的 HTTP 或他文件读写）；gui_registry 迁后全无 `json.` 用法 → 删冗余导入，免 ruff 拦截。
