# 复盘标准 · lottery 诚实复盘 4 级（JS-20261012-11）

> **定位**：配套 `docs/概率概念对照.md`（18 项实战 + §四 10 项防御清单）与 `docs/概率工程50讲_公式参考与核对_v1.md`。
> 本文把「如何诚实复盘一个『某彩种有可预测规律 / 某选号策略更优』的声称」落成**4 个 rigor 等级**的过审清单。
> 任何规律声称**必须逐级过审，未过上一级不得声称通过**；对外宣称「已诚实复盘」须 L1–L4 全链通过。
> **定级**：参考文档（评审流程，非阈值/常量），**不**回写 `金水谣_标准唯一真源.md` §三 阈值表。
> **核心结论**：JS-20261006-02（全彩种 66 项）/ JS-20261012-08（后区 74 项）/ JS-20261012-09（共现 4894 对）均过 L1–L4，结论一致——**彩票无预测力，任何选号策略固定奖期望完全相同**。

## 二、逐级详注

**L1 描述级**：最低门槛。允许「双色球近 30 期红球 23 出现 6 次」「某形态历史命中率 12%」这类**事实陈述**，但必须同步标注「这是描述，不是预测依据」。凡出现「该出了 / 热号会延续 / 冷号该反弹」即违规（对应 §四 S1/S2/S6 赌徒/热手/回归均值错觉）。任何声称想升级，先过 L1：说清楚「对照的随机模型是什么」(#1)。

**L2 基线对照级**：把观测频数 / 命中率与**正确随机模型**对照，报告 p 值。要点：①均匀性卡方用二项方差 `n·p·(1-p)`，不用泊松(#3)；②判据 `chi/df≈1` 即均匀，只报总 χ² 不看 df 会漏判(#4)；③命中率基线 = `1−C(NB−m,KB)/C(NB,KB)`，不能用历史出现频率当总体(#7)。此级单点 p<0.05 **不算显著**——必须进 L3 校正。

**L3 多重比较校正级**：同时跑很多检验时，单点 p<0.05 必然出假阳性（T=4894 时约 244 个）。必须：①家族阈值 `α/T`，Bonferroni(#2)；②跨期聚合 z=`Σobs/√ΣV` 避免逐期小样本挑最大(#8)；③无解析式的统计量用蒙特卡洛模拟 R=3000 次得空分布，验证最大遗漏/极端值是否随机可达(#5/#6)；④共现按结构选公式——set 型 `C(k,2)/C(N,2)`、repl 型容斥(#12/#13)；⑤转移独立性用 2×2 卡方且须校正(#14)。结论：校正后仍不显著 = 无预测力。

**L4 零分布审计级（最高）**：L3 通过只说明「统计上不显著」，但**未验证零分布假设本身成立**。必须再加：①边际均匀性闸门(#17)——共现前先验证各号频数均匀，不均则整 field 排除（七星彩 digit1 z=+8.56 污染共现 z 成假显著的教训）；②数据源审计——确认抽取公平（七星彩频数不均疑似非公平抽取，其分析不可轻信）；③预注册假设，禁止用发现数据的同批数据验假设（数据捕捞 #S3 / 德州神枪手 #S4）；④休市感知——未复盘先查是否休市，别把数据缺失判成数据源故障。L1–L4 全链通过，方可对外宣称「已诚实复盘」。

## 三、升级触发条件（何时必须升到下一级）

- 任何「规律 / 策略更优」声称 → 至少过 L1+L2。
- 同时检验数 T≥20，或跨多期/多彩种聚合 → 必须 L3（否则假阳性失控）。
- 结论要对外发布 / 影响选号建议 / 涉及共现或转移 → 必须 L4（零分布与数据源可信性）。
- 任一上级 FAIL → 整链条 FAIL，结论回退为「与公平随机无显著差异」，不得选择性报告下级 PASS。

## 五、诚实铁律落点

- 取不到数据写「暂缺」，绝不编造(#1)；未复盘先查休市，别误判数据源故障。
- 闸门以全绿姿态失效是最危险的假绿：凡「读数据做检验」必先验证零分布假设(#17)，否则边际偏差污染结论(类比 JS-20261012-03 本轮事项闸假绿)。
- 任何声称想「升级 rigor」，只能往上加检验，不能往下砍——下级 PASS 选择性报告 = 德州神枪手(#S4)。
