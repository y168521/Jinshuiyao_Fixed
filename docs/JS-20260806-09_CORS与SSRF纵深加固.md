# JS-20260806-09 · CORS 与 SSRF 纵深加固

> 第二刀(会话租约/非原子写)已 commit `a37d90d`。本刀为审查盘点「中·安全」④⑤⑥ 的落地，
> 但**经现状核实后修正了审计偏差**：SSRF 主体已自愈，仅余入口残差；CORS `*` 在 3 处仍为真实违例。

## 一、道衍推导（框架三问）

- **问阴阳**：阳 = 对外接口"任意前端可调用"的便利；阴 = 恶意网页跨域读响应（CORS `*`）、
  服务端被诱导访问内网/云元数据（SSRF）。现状阴阳失衡：CORS 过度放开、SSRF 入口未校验。
- **问三才**：
  - 天（规划）= 安全基线 JS-20260728-07/08：CORS **同源反射禁 `*`**；执行/提取接口加
    `_is_local()` + `_is_safe_http_url` 防 SSRF。
  - 地（隔离）= `_is_safe_host` / `_is_safe_http_url` 已建且被 router 各接口复用；但
    `video_extractor` 的 GET 入口漏用、`/status` 漏接 `_set_cors()`。
  - 人（复盘）= 审查盘点实锤 ④⑤⑥，逐条复核实后发现 ⑤ 已自愈（见下），须补残差。
- **问知止**：仅改 CORS `*`(3处) + `video_extractor` 入口 URL 校验 + `explorer` 参数化；
  **不改动** `_is_safe_host` 既有逐跳逻辑、**不重构** router，避免引入新风险。

## 二、现状核实（逐条复核实，修正审计偏差）

| # | 审计原述 (file:line) | 复核结论 | 处置 |
|---|---|---|---|
| ④ | `health.py:84` CORS `*` + `/status` 无 `_is_local` | `*` 属实；`_is_local` 诉求已由 `router._set_cors()` 同源反射满足，`/status` 仅**漏接**该方法（手动写 `*`） | 改 `handle_status` 调用 `handler._set_cors()`，删 `*` |
| ④b | 审计未列：`quant_server.py:203,271` 两处 CORS `*` | 属实，同基线违例（独立 dev 服务） | 加 `_set_cors()` 同源反射，删两处 `*` |
| ⑤ | `video_extractor.py:249/282` 首跳无 `_is_safe_host` | **过时**：`_request_with_retry`(233-277) 已强制 `allow_redirects=False` 且**逐跳** `_is_safe_host` 校验 | 不重复改逐跳逻辑 |
| ⑤b | 审计未列：`_request_with_retry` **入口 URL** 未过 `_is_safe_host` | 属实，残差：首跳目标（用户传入的初始 URL）在首个 GET 前**未校验** | 方法开头加 `if not self._is_safe_host(url): return None` |

## 三、设计

### 3.1 CORS（同源反射，禁 `*`）
- `server/handlers/health.py::handle_status`：删除手动
  `handler.send_header('Access-Control-Allow-Origin', '*')`，改为 `handler._set_cors()`
  （复用 router 的同源反射：`Origin` 与自身服务同端口才回显，否则不带头 → 跨域被拒）。
- `frontend/quant-dashboard/quant_server.py`：新增 `_is_same_origin()` + `_set_cors()`
  （逻辑镜像 router，仅校验 scheme + 端口 == `self.server.server_port`）；在 `_send()`
  与 `do_OPTIONS()` 调用，删除两处 `*`。

### 3.2 SSRF（video_extractor 入口校验）
- `_request_with_retry` 开头加：
  ```python
  if not self._is_safe_host(url):
      logger.warning("[video_extractor] 入口URL被拒(SSRF): %s", url)
      return None
  ```
- `_post_with_retry` 同样加入口校验（防御性，当前无调用方，避免未来误用）。

### 3.3 路径注入（utils.py）
- `subprocess.Popen(f'explorer "{full_path}"')` → `subprocess.Popen(['explorer.exe', full_path])`
  （消除引号/元字符歧义；路径仍受 BASE_DIR 穿越防护约束）。

## 四、并发安全论证
- 三类改动均为**只读校验 / 响应头设置 / 进程启动参数**，无共享可变状态写。
- `_is_safe_host` 为纯函数（无副作用，fail-closed：解析异常返回 False）。
- CORS 头设置幂等。无锁需求，无重入风险。

## 五、回滚预案
- 全部为局部单行/小段改动，单文件 `git revert` 即可。
- 若 CORS 误伤前端：临时回退 `handle_status` 为 `*` 恢复（已记录在 diff，可秒回）。
