# 当日购票数据字段决策（JS-20261012-13）

> 决策时间：2026-10-12 ｜ 方式：集思广益 + 全网检索
> **结论：条件加（加，但限定用途、限定字段、禁止用于优化预测）**

## 一、结论先行

| 问题 | 结论 |
|---|---|
| 加不加「当日购票数据」字段？ | **条件加** |
| 加它能提升预测力吗？ | **不能**（已实证彩票无预测力），只能提升「诚实度」 |
| 最大价值 | 把「命中率错觉」转成「真实净盈亏事实」——目前系统只能说"命中率 X%"，无法回答"实际亏了多少" |
| 最大风险 | 商业化场景下的个人信息合规（属个人财产信息/消费记录） |
| 商业化前 | **必须先过授权评估**（既有铁律：商业化意向 → 接数据源前先过授权评估） |

## 二、为什么「加」：命中率是最危险的错觉

金水谣现有链路是「预测 → 复盘 → 算命中率」。**命中率回答的是"如果我买了会中多少"，不是"我实际赚了还是亏了"。**

用户极易把「命中率 30%」读成「快回本了」。而全网检索到的官方返奖率给出铁的事实：

| 彩种 | 官方奖金池比例（返奖率） | 公益金 | 发行费 | 来源 |
|---|---|---|---|---|
| 双色球 / 超级大乐透 | **51%** | 36% | 13% | 财政部公告 2026 年第 24 号 |
| 福彩3D / 排列三 | **53%** | 34% | 13% | 同上 |
| 快乐8（基诺型） | **58%** | 30% | 12% | 同上 |
| 七星彩 / 七乐彩 | **50%** | — | — | 中彩网 / 玩法规则 |

**即长期每投 100 元，最多只能拿回约 50~58 元，净亏约 42~50 元。** 加购票字段后，系统能把这个「理论上限」与「用户实际返还率」并排展示，让「亏多少」成为可验证的事实而非推断——这正是本项目「无预测力、只优化诚实度」定位的落地。

## 三、为什么「不加不行」的反向考虑（已否决）

- **否决「用它优化选号」**：JS-20261006-02 / 1008 / 1009 已实证 66 项 + 74 项 + 4894 对全部不显著，购票数据同样零预测力。字段**禁止**进入任何选号/权重逻辑。
- **否决「不加」**：不加则系统永远只能输出命中率，等于默许「命中率 = 盈利能力」的错觉，与诚实铁律冲突。

## 四、合规边界（全网检索：个人信息保护法）

「当日是否购票 + 金额 + 彩种 + 期号」属于**个人财产信息中的消费记录**，是个人信息但**不是敏感个人信息**（敏感的是生物识别、宗教信仰、特定身份、医疗健康、**金融账户**、**行踪轨迹**、不满 14 周岁未成年人信息）。

**红线字段（一律不记）**：

| 禁记字段 | 原因 |
|---|---|
| 票号 / 序列号 / 票面照片 | 可关联到具体票证、具备兑价价值，泄露即财产损失 |
| 销售网点 / 地理位置 | 属**行踪轨迹**＝敏感个人信息 |
| 支付账户 / 银行卡 / 支付流水 | 属**金融账户**＝敏感个人信息，需单独同意 |
| 身份信息 / 手机号 | 超出最小必要范围 |

**遵循原则（PIPL）**：最小必要（第 6 条）、最短保存期限（第 19 条）、境内存储、可一键删除（第 47 条）。商业化对外服务前须取得同意并做个人信息保护影响评估。

## 五、字段草案

| 字段 | 类型 | 说明 |
|---|---|---|
| `purchased` | bool | 当日是否实际购票（未买也要能显式记录 false，避免「没数据」被当成「没买」） |
| `purchase_amount` | float（元） | 实际投入金额 |
| `purchase_count` | int | 购买注数 |
| `payout` | float（元） | 实际兑奖所得；未中奖记 0（**不得留空**，空值会被误读） |
| `net` | float（元） | 派生：payout − purchase_amount，**不单独录入** |
| `purchase_note` | str（可选） | 备注 |

**关键设计**：`purchased=false` 必须显式落库。否则「无记录」与「买了但没登记」无法区分——这正是 JS-20261012-12 大乐透断档踩到的同类坑（缺数据 ≠ 没发生）。

## 六、落地建议

1. **存储**：本地 `金水谣数据/purchase_log.json`（不入仓，沿用运行时数据不入仓铁律），与 predictions.json 按期号关联。
2. **展示**：日报新增「实际投入 / 实际返还 / 净盈亏 / 实际返还率」，并与官方返奖率上限（双色球·大乐透 51%）并列对照。
3. **告警**：实际返还率长期显著高于官方奖金池比例 ⇒ 数据录入有误（弃奖、漏记投入），需提示核对。
4. **商业化前**：先过授权评估，取得同意后再采集他人数据；不接付费数据源。

## 七、来源

- 财政部《2025 年彩票公益金筹集分配情况》公告 2026 年第 24 号（各玩法奖金/公益金/发行费比例）
- 财政部月度全国彩票销售情况（m.mof.gov.cn / zhs.mof.gov.cn，免费公开，含 xlsx 附件；2025 年全国销售 6279.69 亿元，乐透数字型 1777.03 亿元占 28.3%）
- 《中华人民共和国个人信息保护法》第 6/19/28/29/47 条（最小必要、最短保存、敏感个人信息界定、删除权）
- 国家网信办《个人信息保护政策法规问答（2026 年 1 月）》（个人财产信息含消费记录；GB/T 45574-2025 敏感个人信息界定）
- 中彩网《快乐8"一骑黑马"：58% 返奖比例傲彩市》（快乐8 返奖 58% / 公益金 30% / 发行费 12%）

> 注：财政部公开的是**宏观月度聚合销量**（全国/分省/分类型），**没有**个人级或逐日购票数据，故本字段只能由用户自行录入，不存在可抓取的免费公开源。
