## 二、逐条明细（50 条）

| # | 主题 | 核心公式 | 用途说明 | 核对 |
|---|---|---|---|---|
| 01 | 前区组合数 | `N_f = C(35,5) = 35!/(5!·30!) = 324632` | 计算前区所有无序选号组合，是单注等可能计数的基础 | 通过 |
| 02 | 后区组合数 | `N_b = C(12,2) = 12!/(2!·10!) = 66` | 计算后区所有无序选号组合，并确定后区样本空间大小 | 通过 |
| 03 | 总样本空间 | `N = C(35,5)·C(12,2) = N_f·N_b = 21425712` | 合并前区与后区的组合规模，得到完整单注的可能总数（组合维度） | 通过（JS-20261002-18 已按建议补全被截断的末句） |
| 04 | 有序抽取计数 | `(35)_5 = 35·34·33·32·31`；`C(35,5) = (35)_5 / 5!` | 区分抽取顺序与最终选号组合，避免把排列误当成组合 | 通过 |
| 05 | 等可能样本点 | `P(ω) = 1/N`；`Σ_{ω∈Ω} P(ω) = 1` | 表示每个完整号码组合在公平随机模型下具有相同概率 | 通过 |
| 06 | 前区命中分布 | `P(K_f=k) = C(5,k)·C(30,5−k)/C(35,5)`，`k=0..5` | 精确计算前区固定命中 k 个号码的超几何概率 | 通过 |
| 07 | 后区命中分布 | `P(K_b=l) = C(2,l)·C(10,2−l)/C(12,2)`，`l=0,1,2` | 精确计算后区固定命中 l 个号码的超几何概率 | 通过 |
| 08 | 联合命中概率 | `P(K_f=k,K_b=l) = P_f(k)·P_b(l)`；`P_{k,l} = P_f(k)P_b(l)` | 组合前区与后区的命中结果，计算对应等级事件的概率 | 通过 |
| 09 | 命中数期望 | `E[K_f] = 5·(5/35) = 5/7 ≈ 0.714`；`E[K_b] = 2·(2/12) = 1/3 ≈ 0.333` | 描述长期重复参与时前后区平均命中数量的理论水平 | 通过 |
| 10 | 命中数方差 | `Var(K) = n·(M/N)·((N−M)/N)·((N−n)/(N−1))`；`N=35, M=5, n=5` | 衡量命中数量围绕平均值波动的离散程度 | 待高清复核（见第三节） |
| 11 | 至少命中一次 | `P(K_f≥1) = 1 − P(K_f=0)`；`P(K_f=0) = C(30,5)/C(35,5)` | 通过补事件计算前区至少出现一次命中的概率 | 通过 |
| 12 | 至少 r 个命中 | `P(K_f≥r) = Σ_{k=r}^{5} P(K_f=k)`；`P(K_f=k) ≥ 0` | 汇总多个精确命中事件，得到达到门槛的总概率 | 通过 |
| 13 | 精确匹配事件 | `P(K_f=k) = \|A_k\|/\|Ω_f\|`；`\|A_k\| = C(5,k)·C(30,5−k)` | 把精确命中事件转为有利样本数与总样本数的比值 | 通过 |
| 14 | 条件概率 | `P(B\|A) = P(A∩B)/P(A)`；`P(K_b=l\|K_f=k) = P_{k,l}/P_f(k)` | 在已知一个事件发生时，重新度量另一个事件的相对概率 | 通过 |
| 15 | 贝叶斯更新 | `P(H\|D) = P(D\|H)·P(H)/P(D)`；`P(D) = Σ_i P(D\|H_i)P(H_i)` | 获得观测数据后更新假设的可信度，而非预测单次号码 | 通过 |
| 16 | 指示变量 | `K_f = Σ_{i=1}^{5} I_i`；`I_i ∈ {0,1}` | 把每个目标号码是否命中转化为可求和的 0-1 变量 | 通过 |
| 17 | 期望线性 | `E[K_f] = Σ_{i=1}^{5} E[I_i]`；`E[I_i] = 5/35 = 1/7` | 将总命中数的平均表现拆解为各指示变量期望之和 | 通过 |
| 18 | 负相关协方差 | `Cov(I_i,I_j) < 0 (i≠j)`；`Var(K) = ΣVar(I_i) + 2Σ_{i<j} Cov(I_i,I_j)` | 说明无放回抽取会使不同号码的命中事件相互制约 | 通过 |
| 19 | 概率母函数 | `G_K(t) = E[t^K] = Σ_k P(K=k)t^k`；`G'_K(1) = E[K]` | 用一个生成函数统一编码离散命中分布及其各阶矩 | 通过 |
| 20 | 多元超几何分布 | `P(K=k) = Π_i C(M_i,k_i)/C(N,n)`；`Σ_i k_i = n` | 处理多类别无放回抽取时各类别命中数量的联合概率 | 通过 |
| 21 | 容斥原理 | `P(∪A_i) = ΣP(A_i) − ΣP(A_iA_j) + …` | 修正多个事件直接相加造成的重复计数问题 | 待高清复核（第二行被裁切） |
| 22 | 排列与组合 | `P(n,k) = k!·C(n,k)`；`C(n,k) = C(n,n−k)` | 在有序选择与无序选择之间建立严格的计数换算关系 | 通过 |
| 23 | 信息熵 | `H(Ω) = log₂ N`；`H = −Σ p_i log₂ p_i` | 量化完整号码空间所包含的不确定性与信息量 | 通过 |
| 24 | 交叉熵 | `H(p,q) = −Σ p_i log q_i`；`H(p,q) = H(p) + D_KL(p‖q)` | 衡量用一个分布描述实际频率时所需的平均编码代价 | 通过 |
| 25 | KL 散度 | `D_KL(p‖q) = Σ p_i log(p_i/q_i)`；`D_KL ≥ 0` | 比较经验分布与理论分布的差异大小 | 通过 |
| 26 | 经验频率 | `p̂_i = (1/m)Σ_{t=1}^{m} I_{t,i}`；`E[p̂_i] = p_i` | 从多期观测中计算某类结果的样本比例 | 通过 |
| 27 | 卡方统计量 | `χ² = Σ (O_i−E_i)²/E_i`；`E_i = m·p_i` | 检验观测频数是否与理论随机分布存在显著偏离 | 通过 |
| 28 | 自由度 | `ν = c − 1 − r`；`χ² ~ χ²_ν` | 确定卡方检验应采用的参考分布形状 | 通过 |
| 29 | 自相关函数 | `ρ(h) = Cov(X_t, X_{t+h})/Var(X_t)`；`ρ(h) ≈ 0 (h>0)` | 检测不同期结果之间是否存在可量化的线性相关 | 通过 |
| 30 | 游程期望 | `E[R] = 1 + 2n₁n₂/(n₁+n₂)`；`R = number of runs` | 检验二元序列中连续同类结果切换次数是否异常 | 通过 |
| 31 | Beta 后验 | `p\|D ~ Beta(α+s, β+f)`；`E[p\|D] = (α+s)/(α+β+s+f)` | 把先验信息与成败观测结合，得到概率参数的后验分布 | 通过 |
| 32 | 二项似然 | `L(p) ∝ p^s (1−p)^{m−s}`；`p̂ = s/m` | 描述固定次数独立试验下观测到指定成功次数的支持程度 | 通过 |
| 33 | DKW 不等式 | `P(sup_x \|F_m(x)−F(x)\| > ε) ≤ 2e^{−2mε²}`；`m↑ ⇒ ε↓` | 给出经验分布与真实分布最大偏差的有限样本上界 | 通过 |
| 34 | 中心极限定理 | `√m·(X̄−μ)/σ → N(0,1)`；`Var(X̄) = σ²/m` | 说明大量独立观测的样本平均为何趋近正态分布 | 通过 |
| 35 | 泊松近似 | `P(X=k) ≈ e^{−λ}λ^k/k!`；`λ = np` | 近似刻画低概率事件在大量试验中的发生次数 | 通过 |
| 36 | 大数定律 | `X̄_m →^P E[X]`；`X̄_m = (1/m)Σ X_i` | 说明样本平均会在重复试验增多时趋向理论期望 | 通过 |
| 37 | 蒙特卡洛估计 | `P̂ = (1/m)Σ_{t=1}^{m} I_t`；`E[P̂] = P` | 通过大量独立随机模拟估计事件发生概率 | 通过 |
| 38 | 模拟标准误 | `SE(P̂) = √(P(1−P)/m)`；`SE ∝ m^{−1/2}` | 量化蒙特卡洛概率估计因有限模拟次数带来的不确定度 | 通过 |
| 39 | 重要性抽样 | `P(A) = E_q[I_A·p(X)/q(X)]`；`w(X) = p(X)/q(X)` | 改变模拟抽样分布以更高效地估计稀有事件的概率 | 通过 |
| 40 | 自助法 | `SE_boot = √((1/(B−1))Σ_b (T_b−T̄)²)`；`T̄ = (1/B)Σ T_b` | 通过重复重抽样估计统计量自身的抽样误差 | 通过 |
| 41 | 分位数 | `q_α = F^{−1}(α)`；`P(X ≤ q_α) = α` | 确定给定累积概率对应的阈值位置 | 通过 |
| 42 | 互信息 | `I(X;Y) = Σ_{x,y} p(x,y)·log[p(x,y)/(p(x)p(y))]`；`X⊥Y ⇒ I = 0` | 量化两个随机变量之间共享信息的多少 | 通过 |
| 43 | Fisher 精确检验 | `P(a) = C(K,a)·C(N−K,n−a)/C(N,n)`；`a_min ≤ a ≤ a_max` | 在小样本列联表中精确检验两个分类变量是否独立 | 通过 |
| 44 | 多重比较 | `α_per ≤ α/m`；`P(one false positive) ≤ α` | 控制同时进行多项检验时整体误报概率的累积 | 通过 |

| 46 | 支付随机变量 | `X = Σ_j x_j I_j`；`E[X] = Σ_j x_j P(I_j=1)` | 把不同奖项收益写成随机变量并计算其概率加权结果 | 通过 |
| 47 | 净期望 | `E[G] = E[X] − c`；`G = X − c` | 在扣除参与成本后评估长期平均净收益 | 通过 |
| 48 | 收益方差 | `Var(G) = E[G²] − E[G]²`；`σ_G = √Var(G)` | 刻画单次净收益围绕其长期均值的波动风险 | 通过 |
| 49 | 几何等待时间 | `P(T=t) = (1−p)^{t−1}·p`；`E[T] = 1/p` | 描述独立低概率事件首次发生前所需的试验次数分布 | 通过 |
