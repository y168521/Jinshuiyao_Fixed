# raw/ 原始证据层

这是金水谣知识库的**第一层（raw 层）**，对应 Karpathy「LLM Wiki」方法论里的 raw 证据层。

## 它是什么
- 存放**未经消化**的原始材料：网页抓取全文、对话原文、问题原始文本、代码片段。
- 它是知识的「事实源头」，原则上**只增不改**——你以后要核对某条知识对不对，来这里找原始依据。

## 和卡片的区别
- `raw/` 里的文件 = 原料（可能很长、很乱、带原文链接）。
- 本目录上层的 `.md` 卡片 = 成品（助手消化后写成的、人能直接读的知识）。
- 一张卡片可以引用多条 raw 证据（在卡片的「相关」字段写 `raw/文件名.md`）。

## 放什么进来
- 你从网上看到的好文章 → 抓全文存这里，并在卡片里引用。
- 你问过的重要问题原文 → 存这里，方便以后追溯。
- 助手联网查到的资料 → 落地到这里，再提炼成卡片。

## 命名
`日期_evidence_简短主题.md`，例如 `20260718_evidence_karpathy_llm_wiki.md`。

> 注意：raw/ 里的文件**不会**进 INDEX.json（不是知识卡片），但会被 `lint_knowledge.py` 体检检查「是否被卡片引用、是否为空」。
