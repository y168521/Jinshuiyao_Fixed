# 金水谣 · AI 防再犯铁律清单（开工必读，强制执行）

> 本清单由经验收集箱中的高频问题提炼（2026-08-04 固化）。
> **每次开工、每次改码前必须对照**。违反任一铁律 = 完成任务不达标。
> 规则分级：🔴 必读（犯过 ≥3 次）/ 🟠 常犯（犯过 2 次）/ 🟡 一次级（偶尔踩）

---

## A. Git 与密钥安全（🔴 最高优先）

| # | 场景 | 铁律动作 |
|---|------|---------|
| A1 | 提交任何文件前 | **先 `git status` 看清单**，逐项确认没有密钥/运行时/冲突文件被卷进来；`git add -A` 前必查黑名单（SKILL.md 铁律 A） |
| A2 | 敏感文件曾被跟踪 | gitignore **对已跟踪文件无效**，必须 `git rm --cached` 才会生效；删完要查 `git log --all -- <文件>` 确认历史 |
| A3 | 密钥/API Key | **永不入库**；写入 `~/.jinshuiyao-secrets/`（唯一位置）；代码读密钥统一走该目录，禁止新开 config.json 存 key 路径 |
| A4 | 坚果云冲突文件 | `*-冲突-*` / `*(冲突)*` 模式永不入库；同步后检查 knowledge/ 下有无冲突残留 |
| A5 | 运行时数据 | predictions/engines/risk_state/cache 等运行时文件永不入库（gitignore 黑名单）；新增"不该入库"的文件必须 **gitignore + noise 列表双登记** |

## B. 代码修改规范（🔴）

| # | 场景 | 铁律动作 |
|---|------|---------|
| B1 | 改任何代码前 | **先读目标函数完整源码**（别凭记忆猜），再读调用方确认行为契约 |
| B2 | 改完代码后 | **必跑 pytest**（903 项）或相关单测；GUI 改动除 pytest 外要**手动验证交互行为** |
| B3 | 修 bug 时 | 先复现 → 定位根因 → 修复 → 用**真实数据/真实事件**验证（不是只看逻辑） |
| B4 | 新写函数 | 保持与项目风格一致（契约/日志/错误处理）；不引入未安装的库 |

## C. GUI 交互（tkinter）（🔴 反复重灾区）

| # | 场景 | 铁律动作 |
|---|------|---------|
| C1 | 改事件绑定 | 返回 `"break"` 会**连 class 级默认行为一起关**（autoscroll/原生多选/焦点分配）——绑了 break 就要自己补齐被关掉的默认行为 |
| C2 | 快捷键/全选/复制 | Treeview/Listbox **无原生 Ctrl+A/Ctrl+C**，必须手动 bind；且焦点要先到位（显式 focus_set 或 root 级兜底） |
| C3 | 同类交互优化 | 一处改了（表格拖拽/快捷键）→ **同类组件全查一遍**（日志/导入弹窗/其它列表），不要只修用户点名的那处 |
| C4 | GUI 状态判断 | 交互类 bug 用事件级验证（实际点击/按键），不能只看代码逻辑 |

## D. 后台任务/数据状态（🟠）

| # | 场景 | 铁律动作 |
|---|------|---------|
| D1 | 写后台任务 | "任务"= 真执行+真写盘+状态流转完整；空转（pass/从不写盘）不算完成 |
| D2 | 判定"待复盘 0" | 先区分：**未开奖占位 0**（预期）vs **已复盘真实 0**（没中）——看 Data.has_period/result 再下结论 |
| D3 | 任务结果判断 | 用 exit code/返回值/实际数据判断，**别用 stdout 文本匹配**；fail-safe 条件要具体（total>0 太弱，要每源>0） |

## E. 同步与文件（🟠）

| # | 场景 | 铁律动作 |
|---|------|---------|
| E1 | 活文档提交后 | 交人中心/总索引/经验箱修改后 **拷回根目录 + 校准 mtime**（GITSYNC 双向，不做会卡死提交） |
| E2 | mtime 判断 | 坚果云同步会改 mtime，比较差异时**用内容哈希（MD5）裁决**，别只看 mtime |
| E3 | 文档表格 | 改表格保持**管道数一致**（表头列数=数据行列数）；说明列内嵌 `|` 必须转义 `\|` |
| E4 | 判断"历史泄漏" | 先**实测文件内容/提交记录**（git show），别只凭文件名或记录下结论 |

| # | 场景 | 铁律动作 |
